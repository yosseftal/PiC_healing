## Resolution

### AC mapping

1. Shared `control-affordance.ts` supplies a visible Quiet boundary, white surface, padding, a two-pixel
   semantic Sage 500 focus ring, and the contrast-safe Purple outline. Group/Symptom text inputs and
   Polarity select adopt it. Intensity retains its native range semantics with a 44px control area;
   the native 20px treatment checkbox uses a 44px clickable label. Navigation Tree, Finish Anyway,
   recovery, form, muscle-test, summary, and Persistence Gate buttons use full-size bordered controls.
   Real-browser regression failed at 26.39px before remediation and passes afterward. Persistence Gate
   retains disabled authentication stubs and routes discard/sign-in through existing actions.
   Review follow-up: disabled utilities use 50% opacity and a default cursor while preserving native
   disabled semantics. The Persistence Gate browser regression failed when both states rendered at
   opacity 1 and now verifies that disabled Apple/Google stubs are visually distinct from enabled sign-in.
2. The header trigger has visible `Utilities` text while retaining its established accessible name.
   A reflected session with guidance units retains utilities during content recovery. Genuinely empty
   content still removes utility/Finish paths; initial resolving content remains guarded. The added
   rendered Player recovery test failed before implementation and now opens the real Persistence Gate
   through sovereign Finish Anyway. Existing empty-content and resolving assertions remain intact.
3. `--motion-pic-drawer-active` maps to the approved 280ms token and to zero under reduced motion.
   CSS enter/exit keyframes integrate with Radix presence so the exit visual remains mounted until
   animation completes. Closed visuals immediately become inert and aria-hidden. Browser assertions
   verify intermediate enter and exit translations, full duration, subsequent removal, LTR/RTL signs,
   reduced-motion removal, trapping, Escape/overlay dismissal, and focus restoration. The motion test
   failed with no active entrance animation before remediation and passes afterward.
   Review follow-up: explicit logical safe-area start/end padding swaps the physical left/right env
   values in RTL, independently of the drawer motion sign.
   Final default-worker verification exposed a browser-protocol timing race in the motion assertion:
   the 280ms entrance could finish before a later evaluate call inspected it. The test now registers
   its animationstart observer before each action, captures and samples within the browser event turn,
   then resumes animation. Duration, signed intermediate LTR/RTL translation, exit inert/aria-hidden,
   subsequent removal, and reduced-motion assertions remain intact. No retries or worker changes were
   introduced. The complete default Chromium suite passed 21/21 with four workers afterward; targeted
   browser-file lint and its 130-column check also passed.
4. Content-card headings use Heading size, weight, and line-height tokens. Card/table keyboard outlines
   are inset beyond their full width so overflow containers cannot clip them. The browser regression
   failed at 17px heading text before remediation and now verifies readable hierarchy and the complete
   inward focus indicator. Wave 9.1 and two existing Player Finish tests now interact with accessible
   main controls after Sheet closure and explicitly reject inert ancestors.
5. Targeted browser checks: 13/13 passed across Player, Sheet, and forms; the subsequent Persistence Gate
   browser regression passed. Targeted rendered-UI checks: initial 47/47 passed; final Player, Wave 9.1,
   muscle-test, and Persistence Gate checks passed 40/40. Scoped `pic-web` typecheck passed after final
   source changes. Targeted ESLint passed; all 23 changed source/test/fixture files are at most 130 columns.
