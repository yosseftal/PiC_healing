A bounded version-1 sessionStorage envelope retains serializable fields, context and presentation/focus targets.
Never-attempted initial Guest fields can resume only with a consistent initial context.
Attempted, revised or authenticated retained work is read-only where no exact public runtime retry can be reconstructed.
No executable closure, private engine index or authenticated historical workspace is hydrated.
Shape, group/field consistency and route prerequisites reject malformed navigation authority.
Read-only recovery preserves its original envelope context across persistence.

Before a therapeutic write, an old editable envelope must be replaced or verifiably invalidated.
